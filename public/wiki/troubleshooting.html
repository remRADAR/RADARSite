Troubleshooting.

Fast paths for the common documentation, Studio, release-link, and build failures in this repository.

This page is versioned with the repository and must be checked against current code before an operational decision.

Evidence boundary

Do not infer deployment, credentials, or live-provider state from this page. Confirm those separately.

(01)

Studio admin does not load

Incident guide

Check the authenticated route, cookie contract, environment variables, and focused Studio contract tests before changing UI code.

(02)

A release link is missing

Incident guide

Run the release-link diagnostics, compare the platform URL against the canonical release identity, and inspect whether the provider link arrived after the initial record.

(03)

A wiki link is broken

Incident guide

List public/wiki/*.html, resolve every local href, and update the home navigation only after the destination page exists.

(04)

Build or typecheck fails

Incident guide

Capture the first actionable error, distinguish environment/database failures from code failures, and record the exact command/result in the release notes.
